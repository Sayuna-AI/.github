# Sayuna AI

AI-powered lesson planning and classroom tools for Philippine teachers.

**Website:** https://sayuna-ai.com

## What we build

Sayuna AI is an app store of 40+ tools for teachers, in one place:

- **Planning and documents:** lesson plan and daily lesson log generators, worksheet and presentation makers, activity and performance-task generators.
- **Assessment:** table of specifications (TOS) and assessment generators, quiz slides, automated item analysis.
- **Classroom utilities:** timer, noise meter, group maker, seat planner, random name picker, scoreboard.
- **Interactive learning:** STEM simulations and 3D science and anatomy apps.
- **AI assistant:** an in-app assistant that helps teachers find the right tool.
